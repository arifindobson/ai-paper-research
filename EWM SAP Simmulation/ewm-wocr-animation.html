Settings that typically sit on a storage type and shape putaway and stock removal.
  • Storage type role – standard storage, identification point, pick point, staging area group, work centre… decides how the type is used.
  • Putaway – with the storage section check, the product’s putaway control indicator lists the allowed sections; with the bin type check, the HU type must fit the bin type (a pallet only goes to a P1 slot).
  • Capacity and mixed storage – e.g. the pallet rack allows one HU per bin, while shelving allows several products per bin (verify in your system).
  • Stock removal – the storage type search sequence and the stock removal rule decide the bin. A rule assigned directly to a storage type overrides the one found through the search sequence.
  • Storage type group – pools quants of several storage types so that one sort (strict FIFO / FEFO) runs across all of them instead of storage type by storage type.
  • Full stock removal – in pallet storage a complete HU can be removed with an HU WT instead of picking pieces (verify).
